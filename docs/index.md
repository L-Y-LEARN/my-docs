\## 我的实践体会



这次实践的核心收获是理解了「文档即代码」的工作方式。以前写文档就是写一个 Word 或者 Markdown 文件发给别人，现在文档和代码放在同一个仓库里，改一行文字推上去，网站自己就更新了，中间不需要手动上传任何文件。



整个流程里我觉得最有价值的是 `--strict` 这个参数。它会把链接失效、导航配置错误这类问题直接当成错误报出来，而不是等到网站发布后才在网页上发现某个链接点不动。相当于给文档做了一次「编译检查」。



另外，GitHub Actions 的自动部署让我第一次直观感受到 CI/CD 是什么。以前觉得持续集成是后端开发才用的东西，其实一个纯静态的文档站点同样能受益。
